## [1.0.0]

### ✨ Added
- Initial release of the NavRoute package
- Graph-based route planning with weighted POI selection
- 8 pathfinding algorithms (BFS, DFS, Dijkstra, A*, and bidirectional variants)
- `RouteWalker` component for easy NPC movement control
- Editor visualization tools for routes and points
- Demo scene with complete setup example
- Full documentation (`Manual.pdf`, `README.md`, `LICENSE.md`, `Support.md`)
